Privacy Policy

App: augustus81 uploader (Google Cloud project augustus81-yt)
Last updated: 2026-11-11

Who uses this app

This app is used only by its owner, August, for his own YouTube channel (https://www.youtube.com/@augustus81). It is not offered to other users.

What Google data it accesses

The app requests only the YouTube permissions needed to upload videos and manage the owner's own channel:

  • https://www.googleapis.com/auth/youtube.upload – upload videos
  • https://www.googleapis.com/auth/youtube.force-ssl – set titles, descriptions, thumbnails and publishing schedule of the owner's own videos

How data is used and stored

  • The app does not collect, sell or share any personal data, and it does not access data of any third party.
  • The OAuth token is stored only on the owner's own computer. It is never uploaded to a server, website or code repository.
  • No analytics, cookies or tracking are used by the app or this website.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file also removes the app's access on that computer.
